# AgroSense AI — UI Prototype

Premium mobile-first agricultural web UI matching the requested AgroSense direction.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Images

The UI references local image files under `/public/images/`.
Add your own:
- farm.jpg
- field.jpg
- farmer.jpg
- maize.jpg
- tomato.jpg
- cassava.jpg
- healthy.jpg

The interface still renders if some images are missing; replace them with authentic African agriculture photography for the final visual.

## Screens included

- Dashboard
- Crop Doctor
- Crop Analysis result
- Farm Intelligence
- Smart Market
- Ask AgroSense
- My Farm / Profile
- Responsive mobile navigation

This is UI only. Connect the Crop Doctor upload flow to your trained ML API later.
